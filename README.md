# RLproductpage
Independent portfolio prototype (not affiliated with or endorsed by Ralph Lauren).
Upload the CONTENTS of this folder to the repo root, then Settings > Pages > Deploy from branch > main / (root).
Edit `data/product.json` to change cards, images and links. An empty `"image": ""` shows a typographic tile.
Images load from publishers' sites and may be blocked or moved; swap in your own files under `assets/img/` if one breaks.
